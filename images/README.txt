SCENIUS BY THE SHORE — PNG IMAGE STARTER PACK

This folder contains 20 separate PNG files cropped from one generated multi-scene collage.
They are useful as visual placeholders/prototype assets for wiring up the landing page.
They are NOT individual high-resolution source generations: some image tiles may contain
compositional compromises and their resolution/detail is limited by the source collage.
For production, regenerate each image separately using the prompt pack and replace these files.

The PNG filenames match the planned landing-page asset names. Check the mobile and desktop
hero crops, and review every image before publishing. All images are generated illustrative
visuals, not documentary photos of an actual Exploring Lagos event.
